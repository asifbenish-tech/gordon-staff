📊 תוצאות

💾 שמירת התוצאות

הקולות נשמרים בטאבלט הזה בלבד. מומלץ להוריד קובץ בסוף כל יום הצבעה. אם יש כמה טאבלטים – מחברים את התוצאות של כולם.

📋 איך עובדים בקלפי

  1. תלמיד/ה מגיע/ה לוועדה ← מסמנים את השם ברשימת הכיתה.
  2. חבר/ת ועדה פותח/ת את הקלפי: 🔑 ועדת הקלפי ← קוד ← פתיחת הקלפי להצבעה.
  3. התלמיד/ה מצביע/ה לבד מאחורי הפרגוד. בסוף נשמע צליל, והקלפי ננעלת מעצמה.
  4. צליל אחד = קול אחד. שמעתם שני צלילים אצל אותו/ה תלמיד/ה? בדקו מה קרה.
  5. מישהו יצא בלי להצביע? הקלפי תינעל לבד אחרי כ־2 דקות, או: 🔑 ← קוד ← סגירת הקלפי.
