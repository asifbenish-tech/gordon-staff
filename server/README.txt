שרת הכניסה של "צוות גורדון" - הקמה חד-פעמית (כ-10 דקות, בחשבון adgordon248@gmail.com)
========================================================================================
הכל בחינם: Apps Script + Firebase בתוכנית Spark. בלי כרטיס אשראי.

לפני שמתחילים: ב-Firebase (פרויקט gordon-staff) צריך שיהיה Authentication מופעל
(Authentication -> Get started). זה כבר נעשה כשהופעלה הכניסה במייל.

1. script.google.com (מחוברים כ-adgordon248) -> "פרויקט חדש". שם: "צוות גורדון - כניסה".
   למחוק את מה שיש בעורך ולהדביק את כל התוכן של server/Code.gs. לשמור.

2. מפתח השירות (סוד! לא לשלוח לאף אחד, גם לא לClaude, ולא לשים בגיט):
   א. console.firebase.google.com -> gordon-staff -> גלגל השיניים -> Project settings
      -> לשונית Service accounts -> "Generate new private key" -> יורד קובץ JSON.
   ב. לפתוח את הקובץ בפנקס רשימות ולהעתיק את כל התוכן.
   ג. בעורך הסקריפט: גלגל השיניים משמאל (הגדרות הפרויקט) -> "מאפייני סקריפט"
      -> "הוספת מאפיין": שם SA_KEY, ערך = מה שהועתק. לשמור.
   ד. למחוק את הקובץ שירד מהמחשב.

3. לבחור בפונקציה setup למעלה ולהריץ (▶). לאשר את ההרשאות (גיליון, מייל, גישה לאינטרנט).
   אם מופיע "Google לא אימתה את האפליקציה": "מתקדם" -> "מעבר אל ..." - זה הסקריפט שלך.
   נוצר גיליון "צוות גורדון - מיילים לכניסה" ומגיע מייל עם הקישור אליו
   ועם השורה "בדיקת החיבור ל-Firebase: עובדת ✓". אם כתוב "נכשלה" - לשלוח לClaude את השורה.

4. למלא בגיליון, בלשונית "מיילים", את המייל של כל איש צוות (עמודה B).
   השמות כבר שם - אותם שמות כמו בלוח המערכות. מי שאין לו מייל לא יוכל להיכנס.

5. "פריסה" -> "פריסה חדשה" -> סוג: אפליקציית אינטרנט.
   להפעיל בתור: אני.  מי יכול לגשת: כל אחד.  -> פריסה.
   להעתיק את כתובת ה-Web App (מסתיימת ב-/exec) ולשלוח לClaude.
   היא נכנסת ל-AUTH_API ב-me.js. עד אז האזור האישי מוסתר באפליקציה.

איך זה עובד
- איש הצוות מקליד ת"ז. הטלפון הופך אותה לקוד חד-כיווני (כמו בלוח המערכות) ושולח רק אותו.
- השרת בודק שהקוד ברשימת ההרשאות של לוח המערכות (access_map.json + עמוד המשתמשים),
  מוצא את המייל בגיליון ושולח קוד בן 6 ספרות. הקוד בתוקף 10 דקות, 5 ניסיונות.
- קוד נכון -> אסימון כניסה של Firebase. מאותו רגע הטלפון זוכר את איש הצוות.
- כל שליחת קוד וכל כניסה נרשמות בלשונית log בגיליון.

ניהול
- איש צוות חדש: להוסיף אותו בעמוד המשתמשים של הלוח (כמו היום), להריץ שוב setup
  (מוסיף את השם לגיליון) ולמלא לו מייל.
- להסיר: להסיר בעמוד המשתמשים ו/או למחוק את המייל בגיליון. תוך 5 דקות הוא לא יוכל
  לקבל קוד. טלפון שכבר מחובר נשאר מחובר עד שיוצאים ממנו - בשלב הזה (מערכת השעות בלבד)
  זה לא חושף כלום שלא פתוח ממילא. לפני שיהיו הודעות, נוסיף בדיקה גם בכל פתיחה.
- מגבלות: עד 3 קודים לאדם ב-10 דקות, עד 40 לכל בית הספר בשעה
  (מכסת המייל של חשבון Gmail היא 100 ביום).
- אם מפתח השירות דלף: Project settings -> Service accounts -> "Manage service account
  permissions" -> למחוק את המפתח, ליצור חדש ולהחליף את SA_KEY (שלב 2).
